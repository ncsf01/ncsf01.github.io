# ncsf01.github.io

🔗 **Site:** https://ncsf01.github.io

## Seções

- **Apresentação:** quem sou, formação atual, objetivos e áreas de interesse

- **Projetos:** projetos acadêmicos (incluindo o projeto API, com janela de detalhes) e pessoais
- **Contato:** GitHub e LinkedIn
