# Crédito Inclusivo

API (Aprendizagem por Projeto Integrado) é o projeto feito em equipe a cada semestre da FATEC, para um cliente real. 1º semestre de 2026, em andamento.

"Empresa" parceira
Prof. Fernando Masanori Ashikaga (FATEC)
Equipe
Kurumin, 9 integrantes. Minha função: Scrum Master e desenvolvedor.
Problema
Muitas pessoas de baixa renda têm o crédito negado pelos grandes bancos, mesmo quando teriam condições reais de pagar. Faltam dados claros para mostrar em quais regiões existe essa demanda reprimida com baixo risco de inadimplência.
Solução
Um site com painel interativo que transforma os dados públicos do Banco Central (SCR) e do IBGE em gráficos e indicadores por região e por estado, ajudando analistas de crédito a encontrar oportunidades de crédito mais inclusivo.
Tecnologias
  • Python
  • Pandas
  • Google Colab
  • Flask
  • HTML5
  • CSS3
  • Git e GitHub
  • Scrum
Minhas contribuições
  • Scrum Master da equipe: acompanhamento das sprints, correções e padronização do código.
  • Código base no Colab para a Sprint 1: inadimplência de recuperação rápida e percentual de dívida saudável vs crítica.
  • Correção e melhoria dos códigos do Colab para o comparativo de taxas de juros entre instituições financeiras e para dívidas e inadimplência por bets.
  • Correção de dados do endpoint usado no gráfico de evolução da população por estado.
